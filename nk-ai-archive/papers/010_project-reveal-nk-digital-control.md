### 3-3. 실험 → 기술 분석 결과

**① 전자서명 체계** (pp. 8–10)
- 2012년경 도입, 2012–2014년 사용자에게 서명 체계가 들어간 버전으로 업데이트하도록 압박함 (p. 8)
- 파일은 두 서명 중 하나가 있어야 실행·열람 가능: **SELFSIGN**(단말이 직접 생성, 단말로 찍은 사진 등에 붙음), **NATISIGN**(정부가 생성, 공식 콘텐츠·앱에 붙음) (p. 9)
- 파일이 단말에 들어오면 즉시 허용 확장자인지와 유효 서명인지 검사하고, 실패하면 **삭제**함. 허용 확장자 목록은 오디오·비디오, 이미지, 문서, .apk (p. 9)
- 업계 표준 **2048비트 RSA** 서명 기반으로 "안전해 보인다"고 평가 (p. 9)
- 최근 버전은 서명 검사가 개별 앱에서 **OS 하위 층**으로 내려가, 웹 브라우저로 파일을 여는 식의 기존 우회법이 더는 통하지 않음 (pp. 8, 10)

**② 열람리력(Trace Viewer)** (p. 10, 21)
- 단말이 켜져 있는 동안 무작위로 사진(스냅샷)을 찍어 지울 수 없는 디렉터리에 저장함. 이 설명은 38 North(2017) 보도를 각주로 인용함 (p. 10, 각주 4)
- 초기 버전은 사용자가 스크린샷을 볼 수 있었지만, 평양 2425 등 최근 버전은 촬영 시각과 아이콘만 보이고 이미지를 열 수 없음 (p. 10)
- 루팅하면 이 스크린샷을 지울 수 있고, 스크린샷 수가 단말 사용 기간을 보여 주기 때문에 중고가를 올리려고 지우기도 함 (p. 21)

**③ 미래(Mirae) 와이파이** (pp. 11–16)
- 2014년 8월 외국 대사관의 개방형 핫스팟으로 인터넷에 접속하는 일이 생기자 당국이 와이파이를 차단했고, 스마트폰에서 와이파이 기능이 사라짐 (p. 11)
- 2018년 려명거리에 미래 와이파이망 등장. 북한 매체는 최대 70Mbps, 앱은 2–33Mbps라고 표기 (p. 11)
- 접속 조건 3가지: 지원 단말(예: 태양 8321), 망 사업자 SIM, 사용자 ID·비밀번호 (p. 12)
- 인증은 표준 **EAP-SIM**(기본), **EAP-AKA**(3G 장비) 사용. 여기에 승인 단말 확인 단계를 추가함. 분석 시 SIM은 없었고, 안드로이드 기본 EAP 구현은 변경되지 않았음 (p. 14)
- 설정 앱 변경: 네트워크 검색, 개방망 알림, VPN, 테더링 설정 제거. 화면 자동 회전, 배터리 사용량, 개발자 모드도 제거 (pp. 15–16)
- 네트워크 이름 "PYY1026MIRAE00007"과 인증 방식이 앱에 하드코딩돼 있어 다른 망에 접속할 수 없음 (p. 16)

**④ 서명 프로그램(참매·비둘기)** (pp. 17–20)
- 보고서는 이를 국가가 허용한(state-sanctioned) 우회 경로로 분류함. 불법 경로는 루팅 (p. 17)
- 파일 목록과 대상 단말의 IMEI(15자리)를 넣으면 SELFSIGN 서명을 붙임. **키가 프로그램에 하드코딩**돼 있고 IMEI만 있으면 됨. 여러 IMEI를 추가할 수 있으나 임의의 단말에서 열리는 서명은 만들 수 없음 (p. 17)
- 표시된 유효기간과 무관하게 2014년(Woolim)부터 2019년(태양 8321) 단말까지 서명이 유효함 → 키와 서명 체계가 한 번도 바뀌지 않았음을 시사 (pp. 17, 19)
- 서명 개수 제한 같은 추가 제약은 발견되지 않음 (p. 19)
- 비둘기는 붉은별 OS **워터마크**도 처리함: 파일 끝 3바이트가 "EOF"인지 확인하고, 유효한 워터마크가 있으면 그만큼(보통 24바이트) 파일 길이를 조정함 (pp. 19–20)
- 두 프로그램이 존재하는 이유(후속 버전인지, 제조사별 브랜드인지)는 불분명 (p. 20)

**⑤ 스마트폰 해킹(루팅)** (pp. 4, 20–22)
- 방법: 노트북에 USB로 연결해 앱을 설치하고, 보안 소프트웨어에 탐지·삭제되지 않게 실행해 루트 권한을 얻음. Mr. Kim은 중국 앱 "Root 方手"를 사용 (p. 20)
- Mr. Park은 두 번 막히고 세 번째에 성공 (p. 20)
- 동기: 앱·사진 필터·미디어 설치, 듀얼 SIM 기능 되살리기, 열람리력 스크린샷 삭제로 중고가 올리기, 시작 화면 변경 등. 정보 소비와 무관한 경우도 많음 (pp. 4, 21)
- **규모 추정**: Mr. Kim은 "사람들 중 10% 미만"이 시도했을 것이라 추정, Mr. Park은 "자기가 아는 대학생의 약 30%"가 했다고 함 (p. 21). 두 사람 모두 루팅은 흔치 않다고 강조
- 지식 경로: 중국 등 해외에 파견된 북한 프로그래머가 정부용 자료와 함께 해킹 도구를 들여옴 (pp. 21–22)
- 시기: Park은 아리랑, 평양 2413에서 성공. Kim은 USB 방식이 평양 2419(2017년 출시)까지 통했고 이후 막혔다고 함 → 당국 대응 시점을 2017–2018년으로 추정 (p. 22)

**⑥ 국가의 대응** (pp. 4, 22, 26–27, 33–35)
- 기술: 평양 2425에서 USB로 메모리에 접근하면 빈 디렉터리만 보임. 보고서는 이를 국내 해킹에 대한 대응으로 "거의 확실"하다고 봄 (pp. 26–27)
- 법: 반동사상문화배격법에 "손전화기 조작 프로그램 비법 설치" 처벌 조항(노동교양/노동교화), 불순출판물·선전물 차단 프로그램이 없는 휴대폰 사용 시 벌금 5만–10만 원, 기관 대상 벌금 100만–150만 원 (pp. 22, 34–35)

**⑦ 기타** (pp. 23–25, 31–38)
- 휴대폰 구입에 약 3개월 소요. 수입 100대 중 70–80대가 브로커를 통해 시장으로 빠진다는 증언 (p. 23)
- 단말 검열 기관으로 109그루빠(탈북민 증언), 출판검열국 79호실, 국가전파감독국 (pp. 24–25)
- 모바일 결제: 2020년 7월 통화 크레딧 거래 제한, '만물상' QR 결제(43인치 TV 264,000원 예시), 전성카드 모바일 버전 (pp. 31–33)
- 이동통신망은 3G W-CDMA로 384kbps 이상 어려움. 2021년 1월 8차 당대회에서 차세대 이동통신 전환 지시 (p. 36)
- 로동신문이 2021년 5월 17일 '정보산업성'을 처음 언급 (p. 38)
- 메타데이터 감시: "현재까지 메타데이터가 대규모로 감시에 활용된다는 증거는 없다" (p. 3)

### 3-4. 결론
- 북한은 기술의 경제적 효용과 정보 통제 사이에서 줄타기를 함. 와이파이의 도입→금지→통제된 재도입, 평양 2425의 USB 차단이 그 예임 (p. 39)
- 스마트폰 해킹은 기존의 단순 우회보다 한 단계 공격적인 행위(보안 소프트웨어 자체를 공격)이며, 해커의 기술은 국가가 시킨 교육에서 나왔다는 역설이 있음 (p. 39)
- 정보 자유 측면에서 긍정적 신호이지만, 국가의 기술 활용 확대는 주민의 사생활을 더 침해할 수 있음 (p. 39)
- 별도의 정책 권고(recommendations) 절은 없음. 서론에서 메타데이터 감시는 "모니터링해야 할 영역"이라고만 언급 (p. 3)

## 4. 해당 연구의 한계점

**저자가 밝힌 한계**
- 미래 와이파이 심층 분석은 단말 부족으로 태양 8321 한 대에서만 했고, 다른 단말도 같다고 "가정"함 (p. 12)
- 분석 당시 미래 SIM이 없어 실제 접속 과정은 확인하지 못함 (p. 14)
- 평양 2425는 모든 메모리 접근 방법이 실패해 내부를 분석하지 못했고 "작업이 계속되고 있다"고 함 (p. 26)
- 루팅 규모는 추정하기 어렵고 인터뷰 대상자들도 널리 퍼졌다고 보지 않았다고 밝힘 (p. 5)
- 서명 프로그램 최초 배포 시점은 알 수 없음 (p. 17)

**내가 본 한계**
- **표본이 매우 작음**: 인터뷰 2명, 심층 분석 단말 2대(그중 하나는 내부 접근 실패). 루팅 비율 "10% 미만 / 30%"는 두 사람의 인상 추정이고, 둘 다 기술 숙련자라 선택 편향이 큼
- **핵심 주장 일부가 추론**: 평양 2425의 USB 차단이 해킹 대응이라는 판단은 시간 순서와 인터뷰에 기댄 추론임 ("almost certainly", p. 27)
- **열람리력 설명이 2차 인용**: 무작위 스냅샷·삭제 불가 설명은 38 North(2017)를 인용함. 평양 2425에선 메모리 접근에 실패했으므로 저장 위치·주기·전송 여부를 직접 검증하지 못함
- **부록 누락**: 서명 체계와 설정 변경의 기술 상세가 부록에 있다고 했지만 이 PDF엔 없음. 재현에 필요한 정보가 부족함
- **내부 불일치**: 반동사상문화배격법 시기를 "2020년 제정"(p. 4), "2020년 말 시행"(p. 22), "2019년 말 도입"(p. 33)으로 다르게 씀. 처벌도 "최소 3개월 노동교양"(p. 22)과 "최대 3개월 노동교화"(p. 34)로 다르게 씀. 인터뷰 대상자도 "중국 국영기업 소프트웨어 엔지니어"(p. 4), "정부 프로그래머"(p. 20), "국가를 위해 해커로 훈련받음"(p. 39)으로 묘사가 조금씩 다름
- **이해관계 공개**: 발간 기관 Lumen은 북한 내 정보 유입을 목표로 하는 단체임(p. 6). 보고서가 이를 숨기진 않지만 '해킹은 긍정적 신호'라는 해석(p. 39)은 이 관점과 맞닿아 있음
- **AI·언어 검열 내용 없음**: 단말의 텍스트 검열, 단어 자동 치환, 말투 탐지, AI 활용에 대한 분석은 전혀 없음 (7절 참고)

## 6. NLP 측면 연구 아이디어

> ⚠️ **이중 용도(dual-use) 주의**: 아래 아이디어는 검열·감시 연구와 맞닿아 있음. 목적은 **감사(audit)·인권 모니터링·2차 문헌 검증**이며, 배포 가능한 감시·검열 도구나 우회(서명 위조, 루팅) 도구를 만들거나 공개하지 않는 것을 전제로 함. 탈북민 증언을 다룰 때는 신원 노출 위험이 있으므로 IRB·연구윤리 검토를 거칠 것.

### 아이디어 1. 북한 디지털 통제 주장의 '출처 계보' 추적과 주장 검증 (claim provenance)
- **문제 정의**: 2차 문헌(학술 논문, 보고서, 기사)이 "열람리력", "워터마크", "AI 말투 탐지" 같은 주장을 할 때, 그 주장이 어떤 1차 근거(기술 분석, 증언, 북한 매체)로 거슬러 올라가는지, 그 과정에서 수치나 범위가 바뀌는지(예: "아는 대학생의 30%" → "탈북민의 10–30%") 추적함
- **데이터**: 본 보고서, 32C3/33C3 발표, 38 North·데일리NK 기사, 이를 인용한 국내외 논문(예: 002). 주장 단위로 문장을 뽑고 인용 관계를 연결
- **방법**: 주장 문장 추출 → 인용 연결 → 원 출처 문장과의 함의 관계 판정(NLI, LLM 보조 + 사람 검증). 수치·한정어(hedge: "likely", "appears", "almost certainly")가 인용 과정에서 사라지는지 따로 표시
- **평가**: 사람이 만든 주장–근거 대응 정답 대비 정확도, 판정자 간 일치도. 핵심 지표는 "근거보다 강하게 인용된 주장" 비율
- **기대 기여**: 북한 기술 연구에서 2차 인용이 증폭되는 문제를 정량화함. README가 짚은 '2차 자료 쏠림' 공백을 직접 다룸

### 아이디어 2. 북한 단말 탑재 앱·사전 텍스트로 본 '공식 언어 자원' 목록화
- **문제 정의**: 평양 2425에는 조선말사전, 다국어사전, 정보기술용어사전, 조선대백과사전 등 언어 자원 앱이 들어 있음(pp. 29–30). 북한이 단말에 기본 제공하는 언어 자원을 목록화하고, 공개된 북한 사전·용어집과 대조해 문화어 표준 어휘 자원의 범위를 파악함
- **데이터**: 보고서의 앱 목록(발행처·연도), 공개 출판된 북한 사전류의 표제어(합법적으로 접근 가능한 범위)
- **방법**: 앱 메타데이터 구조화, 표제어 수준의 남북 어휘 대조(정렬·차이 분석). 단말 바이너리 분석은 하지 않음
- **평가**: 대조 사전의 정밀도(사람 검수), 남북 어휘 차이 유형 분류의 일치도
- **기대 기여**: 북한어 NLP(정규화, 기계번역)용 공개 어휘 자원. 검열 도구가 아니라 언어 자원 연구로 설계함

### 아이디어 3. 북한 정보통신 관련 공식 보도의 이벤트 타임라인
- **문제 정의**: 보고서가 조선중앙TV·로동신문에서 읽어 낸 사건(미래 와이파이 등장, 모바일 결제, 정보산업성 등장, 차세대 이동통신 지시)을 체계적으로 수집해 기술 도입–통제–법제화 타임라인을 만듦
- **데이터**: 로동신문·조선중앙통신 공개 기사(텍스트), 보고서·002의 사건 목록을 시드로 사용
- **방법**: 개체명 인식(기관, 기술명, 법령), 이벤트 추출(도입·제한·법제화), 날짜 정규화. LLM 보조 추출 후 사람 검증 (001의 방법 참고)
- **평가**: 수작업 정답 대비 이벤트 F1, 보고서가 언급한 사건의 재현율
- **기대 기여**: 002 아이디어 4(통제·우회 타임라인)의 '국가 측' 절반을 공식 매체 근거로 채우는 공개 데이터셋
