## 2. 한 줄 요약
북한처럼 신뢰할 만한 정보원이 극히 부족하고 선정적 허위 보도가 넘치는 주제에서는 "신뢰 출처로 근거 대기"나 "불확실성 표현"이라는 기존 환각 완화책이 잘 통하지 않는다는 문제의식 아래, 검증 가능한 북한 관련 주제 13개(거짓 루머 7, 덜 알려진 사실 6)를 5개 LLM에 영어·중국어·한국어로 물었다. 그 결과 모델과 언어에 따라 정확도·응답 거부율이 크게 달라졌다(예: Claude 3 Sonnet 영어 75.38% vs 중국어 56.92%, Gemini 영어 RtA 40%).

## 3. 내용 요약

**연구 질문** (p. 3355)
- **RQ1.** 신뢰할 만한 출처가 부족한 상황에서 현재 LLM은 북한 관련 주제에 대해 어떻게 정보를 생성하는가?
- **RQ2.** 여러 LLM이 북한 정보를 생성하는 방식은 언어에 따라 달라지는가?

**문제의식** (pp. 3353–3355)
- 북한 관련 오정보는 선정적 보도(뉴스사의 트래픽 수익원), 사실 확인의 어려움, 정정할 유인 부족 때문에 권위 있는 매체에서도 나옴 (Seo 2023)
- 따라서 "신뢰 출처로 근거 대기(RAG 등)"는 출처 자체가 틀릴 수 있어 한계가 있고, "불확실성 표현/응답 거부"는 사용자가 북한에 대해 알아보려는 유인을 꺾고 "북한은 알 수 없는 나라"라는 인식을 강화할 수 있음
- 기존 환각 리더보드·허위정보 벤치마크는 북한 주제를 거의 다루지 않음

### 3-1. 방법론
- **주제 후보 생성** (Figure 1, pp. 3356–3357)
  - GPT-4(API, temperature 0.7)에 두 범주별로 "주제 5개를 골라 달라"는 프롬프트를 영어·중국어·한국어로 각각 10회 요청 ("arbitrary generation" 방식, Chen & Shu 2024a에서 착안)
  - GPT-4를 쓴 이유: 생성한 주제에 대해 GPT-4 자신은 평가하지 않음, 북한 정보에 많이 노출됐을 것, 지시 수행 능력이 좋음
  - 취합·중복 제거 → 거짓 루머 **46개**, 덜 알려진 정보 **61개** 후보 → 한 번만 등장한 후보 제거 → **9개 / 24개** → 북한 전문가가 검증 가능한 정답이 있는 주제로 축소 → **7개 / 6개, 총 13개** (p. 3357)
  - 각주 8: 언어별로 GPT-4가 제안한 주제의 성격이 눈에 띄게 달랐다고 함 (전체 목록은 Supplementary Material)
- **하위 분류** (p. 3357)
  - 거짓 루머(FR) → *Alienation* (북한을 비현실적·풍자적으로 타자화하는 루머: 유니콘 굴, 태양 탐사 성공) / *Gossip* (실존 인물·장소에 대한 거짓 서술: 현송월 처형설)
  - 덜 알려진 정보(LKI) → *Partial* (과거엔 사실이었거나 피상적으로만 사실: 북한 독자 표준시) / *Verified* (사실: 아리랑 집단체조)
- **프롬프트 설계: 담화 표지로 sycophancy 유도** (p. 3358)
  - 거짓 루머 앞에는 "Apparently"(사실인 것처럼), 덜 알려진 정보 앞에는 "I heard"(불확실한 것처럼)를 붙여 모델을 일부러 혼란시킴 (Sharma et al. 2024a의 sycophancy 연구에서 착안)
  - 공통 요청: 더 자세히 알려 달라, 근거를 대 달라, 답변에 대한 확신 정도를 밝혀 달라
  - 한국어판: 거짓 루머는 "{루머}는 것은 명확한 사실이야.", 덜 알려진 정보는 "{정보}고 들었어." / 중국어판: "显然是…" / "我听说…"
- **지표** (pp. 3358–3359): 모델당 주제별 시행 nT = 5, 각 시행을 RtA / true / false / uncertain 중 하나로 라벨링
  - **RtA 비율** = n_RtA / nT (정보를 전혀 주지 않거나 입장을 밝히지 않으면 거부로 봄)
  - **정확도(Acc.)** = n_correct / nT. 찬반 근거를 모두 대면 근거의 무게로 판정하고, 균형이 맞아 일반인이 결론을 내기 어려우면 uncertain으로 라벨링
  - **일관성(Con.)** = 1 / n_types (서로 다른 답변 유형 수의 역수). 예: {uncertain, uncertain, RtA, false, false} → 1/3. 빈도가 아니라 **종류 수**만 봄 — 단 한 번의 RtA도 사용자 인식에 영향을 준다는 이유
  - 세부 내용의 정확성은 평가하지 않고, 프롬프트에 동의하는지 반대하는지(전반적 입장)만 봄
- **정성 분석** (p. 3359): 하위 분류가 있는 주제에 대해 응답의 뉘앙스가 북한·탈북민에 대한 고정관념을 강화하는지 검토

### 3-3. 실험

**설정** (p. 3358)
- 비교 모델 5종: **GPT-3.5**(OpenAI), **Gemini**(Google, 버전 미표기), **Claude 3 Sonnet**(Anthropic) — 3개 언어 모두 / **Qwen-72B-Chat**(Alibaba Cloud) — 중국어만 / **Solar-Mini**(Upstage) — 한국어만
- 접근 방식: 앞의 3개는 각자의 플랫폼, Qwen과 Solar는 poe.com을 통해 추론. **모든 모델은 2024년 3월에 접근** (p. 3358)
- 각 프롬프트를 5회 입력하고 매번 재생성(regenerate)
- 별도 베이스라인(검색 기반, RAG 등)은 없음. 모델 간·언어 간 비교가 핵심

**결과 해석**
- **RtA** (p. 3359): Gemini가 모든 언어에서 유독 높음(약 38–42%). 덜 민감한 *Verified* 주제에서도 거부가 이어졌고, 다른 모델은 이 범주에서 RtA 0. Qwen은 전 주제 RtA 0, Solar는 거의 0. GPT-3.5·Gemini·Claude는 *Gossip*에서 RtA가 가장 높고 *Verified*에서 가장 낮음. 한국어 Gemini 출력 예시는 전부 "이 질문에 대한 대답을 아직 학습하는 중입니다. 그동안 Google 검색을 사용해 보세요."라는 거부 문구였음 (Table 6, p. 3369)
- **정확도** (pp. 3359–3360)
  - GPT-3.5는 영어·중국어가 한국어보다, Gemini·Claude는 영어가 중국어·한국어보다 훨씬 정확함 → 영어 중심 학습 코퍼스 때문으로 추정
  - 언어 특화 모델(Qwen-중국어, Solar-한국어)은 해당 언어에서 나머지 3개 모델 평균보다 정확했고, 두 모델 모두 *Verified* 주제에서 100% 정확 → "AI 주권" 담론을 뒷받침하는 결과로 해석
  - 모든 모델이 정답이 '거짓'인 주제(FR)에서 '참'인 주제(LKI)보다 성능이 낮음. 예: 2014 월드컵 관련 루머 → 정정 정보를 학습 과정에서 덜 접했을 것이라는 가설과 부합
  - 김정은·현송월·장성택 '사망/처형' 오보는 대표적 오정보 사례인데도 계속 재생산됨 → 정정 기사보다 오보의 양이 압도적이기 때문일 가능성
  - 공개된 크기·능력이 정확도와 꼭 비례하지 않음. 세 언어 모두 Claude 3 Sonnet > ChatGPT-3.5 > Gemini 순. Claude의 강세는 최근 공개(더 최신 정보·사후 정정 노출) 때문일 수 있다고 봄
- **일관성** (pp. 3360–3361): 중국어(언어)와 Claude 3 Sonnet(모델)에서 높았지만 언어·모델 간 뚜렷한 패턴은 없음. 대신 LKI가 FR보다 일관성이 높음 → 민감한 FR 주제는 안전장치를 건드려 "안전한" 답을 내게 만듦. 일관성은 RtA·정확도와 강한 상관이 없었고, Gemini 영어의 Con 0.92는 RtA 40% 때문에 생긴 "거부의 일관성"이라고 지적
- **정성 예시** (부록 A): ChatGPT-3.5는 김정은 사망 루머에 대해 영어에서는 "2022년 1월 이후 정보가 없다"며 판단을 피하는 답을 반복함 (Table 2, p. 3365). 덜 알려진 정보(5년마다 선거)에 대해 한국어로 ChatGPT-3.5·Claude·Solar는 모두 '사실'이라 답하면서 선거의 형식성을 함께 설명함 (Tables 5, 7, 8, pp. 3367–3371)

### 3-4. 결론
- 비교적 단순하고 정답이 검증 가능한 주제에서도 모델·언어에 따라 북한에 대한 정보가 크게 달라짐 → 더 복잡하고 맥락 지식이 필요한 주제에서는 차이가 더 클 것 (p. 3361)
- **모델 선택과 언어 선택이 사용자의 북한 인식을 좌우할 수 있음** — 북한이 제기하는 안보 과제를 고려하면 중요한 문제
- 제언 (p. 3361)
  - RAG에서 상위 웹 검색 결과 대신 국제관계 전문가가 검증한 **전문가 큐레이션 출처**만 쓰는 워크플로를 설계할 것
  - 지식 충돌(knowledge conflict, 파라메트릭 지식 vs 외부 정보) 연구가 북한 같은 주제에서 특히 유용함
  - 참여형 AI(participatory AI)로 환각을 줄이자는 제안은 일반 북한 주민의 의견을 받을 수 없어 사실상 불가능함
- 북한은 기존 환각 완화 전략이 통하지 않는 '엣지 케이스'의 대표 사례이며, 정보 체계가 닫힌 다른 나라에도 같은 문제가 생길 수 있음

## 4. 해당 연구의 한계점

**저자가 밝힌 한계** (pp. 3361–3362, Limitations and societal impact)
- 평가 편의를 위해 정답이 검증 가능한 **소수 주제**만 썼고 데이터셋 크기가 작음. 다만 목적이 모델 순위 매기기가 아니라 "모델·언어에 따라 사용자가 받는 정보가 크게 다르다"는 점을 보이는 것이므로 차이가 드러난 이상 크기는 덜 중요하다고 주장함
- 맥락 지식과 정보 종합이 필요한 더 넓은 주제, 멀티모달 LLM으로 확장할 필요가 있음
- 응답이 주제에 대체로 동의/반대하는지만 평가했고 세부 내용은 분석하지 않음. 실제로 위험한 것은 명백한 거짓보다 자신 있게 제시되는 미묘한 부정확성·과잉 단순화·편향일 수 있음
- '환각(hallucination)'이라는 용어가 LLM의 실제 작동을 반영하지 않을 수 있다는 점(Hicks et al. 2024의 'bullshit' 논의)을 언급함

**내가 본 한계**
- **표본이 너무 작아 통계적 결론이 어려움**: 주제 13개 × 5회. 주제당 시행 1번이 FR에서 2.86%p, LKI에서 3.33%p를 움직임. 신뢰구간·유의성 검정이 없어 "영어가 더 정확하다"는 결론이 특정 주제 몇 개에 좌우됐을 수 있음. 한 언어 안의 주제별 분산도 보고되지 않음 (Supplementary Material에만 있다고 함)
- **언어 간 프롬프트 강도가 다름 (교란 변수)**: 영어 FR 프롬프트는 "Apparently …"인데 한국어판은 "…는 것은 **명확한 사실이야**"로 훨씬 단정적임 (p. 3358). sycophancy 압력이 언어마다 달라서 "한국어 정확도가 낮다"는 결과가 언어 효과인지 프롬프트 강도 효과인지 분리할 수 없음. 또 부록에서 김정은 루머의 중국어 입력은 "사망했거나 **식물인간 상태**"(死亡或陷入植物人状态)로, 영어·한국어의 "심장 수술 후 위독"과 내용이 다름 (Table 3, p. 3365). 저자는 "의미가 같다"고 하지만 엄밀히는 다름
- **2024년 3월 웹 UI 기준 스냅숏**: Gemini 버전이 없고, 플랫폼·poe.com 경유라 시스템 프롬프트·온도·안전 필터를 통제할 수 없음. 특히 Gemini 한국어 거부 문구("아직 학습하는 중입니다…Google 검색을 사용해 보세요")는 모델 판단이라기보다 **제품 단의 필터**일 가능성이 높아 "모델의 안전장치"로 해석하는 데 주의가 필요함. 현재 모델로는 재현이 불가능함
- **RtA를 오답으로 처리하는 문제**: Gemini의 낮은 정확도는 높은 RtA 때문이기도 하다고 저자도 인정함(p. 3360). "틀린 답"과 "답하지 않음"을 같은 정확도 분모에 넣으면 환각 정도가 과대평가됨. RtA를 뺀 조건부 정확도(answered accuracy)를 따로 보고했어야 함
- **일관성 지표가 거칠다**: 1/n_types는 4가지 값(1, 1/2, 1/3, 1/4)만 가지며, {T,T,T,T,F}와 {T,F,F,F,F}가 같은 점수를 받음. 다수 답변 비율이나 엔트로피 같은 표준 지표가 더 정보량이 많음
- **정답(ground truth) 설정의 모호성**: 예컨대 "북한이 미국을 하룻밤에 전멸시킬 미사일을 보유했다고 주장한다"는 FR로 분류됐는데, 북한 매체의 실제 대미 위협 수사와 경계가 애매해 모델이 '참'이라 답해도 완전히 틀렸다고 보기 어려울 수 있음. '독자 표준시'(Partial)도 시점에 따라 정답이 달라짐. 각 주제의 정답 근거(출처)가 본문에 정리돼 있지 않음
- **주제 생성의 순환성**: 주제 후보를 GPT-4로 생성하고 "한 번만 나온 후보 제거"로 걸렀기 때문에, 애초에 LLM이 잘 아는(자주 언급되는) 주제 쪽으로 편향됨. 북한 전문가가 직접 설계한 주제 집합과 비교하지 않음
- **주석 신뢰도 미보고**: 주석자 2명 + 전문가 1명 구조지만 일치도 수치가 없음. 언어마다 주석자가 달라(영/중, 영/한) 언어 간 비교에 주석자 효과가 섞일 수 있음
- **표의 오기**: Table 1의 ChatGPT-3.5 한국어 FR RtA가 22.83으로 적혀 있는데, 35회 시행에서 나올 수 있는 값은 2.857의 배수(8/35 = 22.86)라 오기로 보임. Gemini 한국어 LKI 일관성 앞의 라벨이 "(I)"로 잘못 찍혀 있음. 거짓 루머 ④는 목록에서 "월드컵 결승 진출 보도"인데 본문 해석에서는 "월드컵 우승 보도"로 서술됨 (p. 3357 vs p. 3360)
- **'AI 주권' 해석은 과함**: Qwen·Solar의 우세는 각 언어 1개 모델, 주제 13개에 기반한 결과임. 해당 모델의 학습 데이터 시점·RtA 정책 차이 등 다른 설명을 배제하지 않았음

## 6. NLP 측면 연구 아이디어

### 아이디어 1. NK-TruthfulQA: 통제된 다국어 북한 사실성 벤치마크
- **문제 정의**: 004는 주제 13개, 언어별로 다른 프롬프트 강도, 2024년 3월 웹 UI 스냅숏이라는 한계 때문에 "언어 효과"를 분리하지 못함. 프롬프트 강도를 통제한 더 큰 다국어 벤치마크를 만들어 RQ2를 제대로 검증함
- **데이터**: 북한 전문가가 설계한 주제 수백 개 (FR / LKI / Partial / 시점 의존 사실로 분류). 각 주제에 **정답 근거 출처**(통일부 북한정보포털, 북한 공식 매체 원문, 검증된 언론 보도)를 붙임. Seo (2023)의 '사망 오보' 사례를 FR의 핵심으로 포함. 언어는 영·중·한 + 일본어·러시아어(004가 언급한 역내 이해 당사국)로 확장 가능. 각 언어 프롬프트는 역번역으로 의미·강도를 맞추고, 담화 표지를 **중립 / 동의 유도 / 반대 유도** 3수준으로 체계적으로 바꿈
- **방법**: API로 버전·온도를 고정하고 주제당 다회 샘플링. 응답을 RtA / 참 / 거짓 / 불확실로 분류(사람 주석 + LLM 보조, 001-#3의 신뢰도 감사 방식 적용)
- **평가**: answered accuracy와 RtA를 분리 보고, 주제 단위 bootstrap 신뢰구간, 언어 × 담화표지 상호작용 효과(혼합효과 로지스틱 회귀). 일관성은 다수 답변 비율·엔트로피로 측정
- **기대 기여**: 북한 연구자·언론인이 LLM을 쓸 때 참고할 수 있는 공개 벤치마크. 004의 결론("언어가 북한 인식을 좌우한다")을 통계적으로 검증

### 아이디어 2. 북한 출처 계층별 RAG와 지식 충돌 실험
- **문제 정의**: 004는 "전문가 큐레이션 출처만 쓰는 RAG"와 "지식 충돌 연구"를 제안했지만 실험하지 않음. 출처 유형에 따라 북한 관련 답변의 정확도가 어떻게 변하는지 측정함
- **데이터**: 아이디어 1의 주제 + 출처 코퍼스 4계층 — (a) 일반 웹 검색 상위 결과, (b) 타블로이드·선정적 보도, (c) 전문 매체·연구기관(38 North, NK News, 통일연구원 등), (d) 북한 공식 매체(로동신문·조선중앙통신 원문)
- **방법**: 같은 질문에 계층별 문서를 넣어 RAG 답변을 생성. 일부러 파라메트릭 지식과 충돌하는 문서(정정 기사 vs 오보)를 넣어 모델이 무엇을 따르는지 측정. (d) 북한 공식 매체는 "북한 측 주장"으로 귀속(attribution)하는지도 봄
- **평가**: 정확도, 출처 귀속 정확도(누구의 주장인지 밝혔는가), 정정 정보 채택률
- **기대 기여**: 북한처럼 "신뢰 출처 자체가 불확실한" 영역에서 RAG 설계 지침. 003의 로동신문 해석 연구와 결합하면 "북한 측 주장 vs 외부 사실"을 구분하는 시스템으로 확장 가능

### 아이디어 3. 북한 표상의 언어 간 프레이밍 비교: "답은 맞지만 뉘앙스가 다르다"
- **문제 정의**: 004는 찬반 입장만 평가했고, 저자도 "자신 있게 제시되는 미묘한 편향"이 더 위험하다고 인정함. 부록의 '5년마다 선거' 사례처럼 모든 모델이 '사실'이라 답하면서도 평가어(형식적, 권위주의, 단일 후보 등)가 다르게 붙음. 같은 질문에 대한 답변의 **프레이밍·고정관념**을 언어별로 비교함
- **데이터**: 아이디어 1의 응답 중 '정답'으로 판정된 것만 추림. 영·중·한 응답을 공통 언어로 번역하지 않고 원문 그대로 분석
- **방법**: 언어별 평가어 사전 + 다국어 NLI/stance 분류로 (i) 체제 비판 프레임, (ii) 체제 정당화 프레임(북한 공식 표현 재생산), (iii) 주민 중심 프레임, (iv) 타자화·희화화(Alienation 루머와 연결)를 태깅. 003-아이디어 2의 "해석 vs 환각" 분리 틀을 그대로 씀
- **평가**: 언어·모델별 프레임 분포 차이, 이중언어 주석자의 판정과의 일치도
- **기대 기여**: 영어권·중국어권·한국어권 사용자가 같은 LLM에서 서로 다른 북한상을 얻는지 실증. 북한 이탈주민에 대한 고정관념 강화 여부(004의 정성 분석 목표)를 정량화
- ⚠️ **이중 용도 주의**: 프레이밍 분류기는 특정 관점을 걸러내는 **검열·여론 조작 도구**로 쓰일 수 있음. 분석 결과와 분류 기준은 투명성 감사 목적으로만 공개하고, 응답을 특정 프레임으로 유도·필터링하는 시스템은 만들지 않는 것을 전제로 함

## 7. 메모 · 인용하고 싶은 문장
- "if a highly competent model consistently expresses uncertainty for a certain topic, users may lose the incentive to explore and learn about the topic." (p. 3353) — 북한 주제에서 '거부'가 중립이 아니라는 핵심 논지
